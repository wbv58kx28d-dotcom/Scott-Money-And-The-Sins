# legacy/

Drop the original single-file prototype here as **`scott-money-battle.html`**
(download it from the Battle 1 artifact in claude.ai).

It is reference only. The game never loads it. Per `CLAUDE.md` §5 it is the
source of truth for every combat number, so once it's here, the modules in
`src/` get reconciled against it. See "Build status" in `HANDOFF.md` for the
list of values that were reconstructed while it was missing.
