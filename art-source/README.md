# art-source/

Original GPT character and background images, kept for re-cuts at other sizes.
The game never loads anything from here.

Everything in this folder except this README is git-ignored by default, because
the originals are large. To keep them in the repo instead, either:

- remove the two `art-source` lines from `.gitignore`, or
- track them with Git LFS: `git lfs track "art-source/**"`.
